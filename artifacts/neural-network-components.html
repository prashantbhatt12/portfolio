Inside a Neural Network

A 10-slide visual presentation that explains the six core components of a neural network and shows what happens when you train one, using my own experiments in the TensorFlow Playground.

Type: Visual presentationCourse: AIML-501 Model DevelopmentTerm: Fall 2026
Download slides (PDF) Open in a new tab

Introduction

Neural networks power almost everything in modern AI, from image recognition to large language models, but to most people they feel like a black box. This presentation breaks a neural network down into the six parts that every network shares and shows them working in real experiments.

Description

The deck has 10 slides:

  • An architecture diagram showing how data flows from the input layer through hidden layers to the output, and how the loss flows back to update the weights.
  • One slide each for layers and neurons, weights and biases, activation functions, loss functions, and optimization algorithms, each with a simple visual.
  • Two slides of experiments from the TensorFlow Playground, comparing different network sizes on circle and spiral datasets.
  • A summary slide on why visualizing neural networks matters and the key insights from the exercise.

Objective

To clearly define the key components of a neural network, show how they fit together visually, and build hands-on intuition by training my own models instead of only reading about them.

Process

  • Reviewed the workshop resources on neural network components.
  • Trained models in the TensorFlow Playground, changing the dataset, number of hidden layers, neurons, input features and activation function, and recorded the test and training loss for each run.
  • Picked the experiments that showed the clearest contrast: 0 vs. 1 hidden layer on circle data, and a small network failing on spiral data.
  • Designed diagrams for the overall architecture, a single neuron, the activation curves and the training loop, keeping the text on each slide short.
  • Built the slides as a web page and exported them to PDF and images for this portfolio.

Tools and Technologies Used

TensorFlow Playground for the experiments, HTML, CSS and SVG for the slides and diagrams, Playwright to export the PDF and images, and an AI assistant to help with drafting and layout.

Value Proposition

This artifact shows that I can explain a complex AI concept simply and visually, and back it up with hands-on experiments. It can be used as a quick primer for students, analysts or business stakeholders who need to understand what a neural network is doing before making decisions about using one.

Unique Value

My first artifact compared many algorithms at a high level. This one goes deep on a single model type and adds my own experimental evidence. Coming from security engineering, I focused on what you can actually observe and verify, like loss curves and weight sizes, so the presentation emphasizes how to tell whether a model is learning, not just how it is built.

Relevance

Neural networks are the foundation of deep learning and generative AI. Understanding layers, weights, activations, loss and optimization is necessary for building, tuning or even responsibly using these models. The lessons from the experiments, like matching model size to the problem and watching training vs. test loss, apply directly to real projects.
