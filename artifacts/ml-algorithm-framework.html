Machine Learning Algorithm Framework

A one-page visual guide that classifies eleven core machine learning algorithms by how they learn and maps each one to the domains it is used in.

Type: InfographicCourse: AIML-501 Model DevelopmentTerm: Fall 2026
Download PDF Open full-size image

Introduction

There are dozens of machine learning algorithms, and for someone new to the field it is hard to know which one fits which problem. This framework puts the most important ones on a single page so the differences between them are easy to see at a glance.

Description

The infographic covers eleven algorithms: Linear and Logistic Regression, Decision Trees, Random Forest and Gradient Boosting, K-Nearest Neighbors, Convolutional Neural Networks, Transformers, K-Means Clustering, Principal Component Analysis, Autoencoders, Generative Adversarial Networks and Diffusion Models. It includes:

  • An algorithm card for each one, with its learning type (supervised or unsupervised), application domains, a plain-language explanation of how it works, and real-world use cases.
  • Color-coded domain tags for Tabular Data, Computer Vision, NLP and Generative AI.
  • A comparison table showing each algorithm's primary and secondary domains and how easy it is to interpret.
  • A timeline from classic machine learning to deep learning to generative AI.
  • Three quick questions to help choose the right algorithm for a problem.

Objective

To identify and categorize key machine learning algorithms, illustrate how they relate to and differ from each other, and create a reference I can keep using throughout my program and in my work.

Process

  • Reviewed the course resources on the differences between AI, ML, deep learning and generative AI.
  • Selected algorithms that cover both learning styles and all four domains, making sure generative AI was well represented.
  • Grouped them into supervised and unsupervised columns, since "do you have labels?" is usually the first question when choosing a model.
  • Wrote a short explanation for each algorithm and limited it to two sentences, so it stays readable for a non-technical audience.
  • Added a comparison table and an evolution timeline to show how the algorithms connect, not just list them.
  • Designed the layout as an HTML page and exported it as a high-resolution image and PDF.

Tools and Technologies Used

HTML and CSS for the layout and design, the Inter typeface, a headless browser (Playwright) to export the PNG and PDF, and an AI assistant to help research and draft content. Concepts reference scikit-learn documentation and course readings.

Value Proposition

This artifact shows that I can take a broad, technical topic and organize it into something clear and useful. It gives students, analysts and team leads a fast way to understand which algorithm fits which kind of problem, which is often the first and most important decision in a machine learning project.

Unique Value

Most algorithm cheat sheets focus only on accuracy and use cases. Because of my background in cybersecurity and a regulated industry, I added interpretability as a comparison point, since in areas like finance and security being able to explain a model's decision matters as much as how accurate it is. Several of the use cases, like spotting unusual login behavior, also come from the kind of problems I work on.

Relevance

Choosing the right algorithm saves time and avoids building something overly complex. As more teams start using AI, there is a real need for people who can explain these choices clearly to both engineers and decision makers. This framework is also a foundation for the rest of my program, where I'll build and evaluate these models hands-on.
